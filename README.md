### **Project Title: Faces of Polygon – Interactive Team Directory**

**Project Overview** The **Faces of Polygon** project is a custom-developed web application designed to serve as a dynamic, interactive directory for the employees of **Polygon Technology**. Developed as a core part of a brand research assignment, this project moves away from static "About Us" pages to create a living ecosystem that highlights the human element behind the tech brand. The application focuses on clean UI/UX, high-performance asset delivery, and automated data management.

**Key Features & Functionality**

- **Dynamic Employee Grid:** The website features a responsive grid layout that displays all team members using high-quality, compressed portraits managed through a custom pipeline.
- **Intelligent Filtering:** To ensure scalability, the platform includes a robust filtering system. Users can sort through the "Faces of Polygon" by department, role, or specific expertise, making it easy to navigate a growing team.
- **Randomized Discovery:** To keep the user experience fresh, a randomization feature allows the directory to shuffle employee profiles on each visit, ensuring equal visibility for all team members across the organization.
- **Automated Asset Pipeline:** The project utilizes an advanced backend workflow where phone-captured selfies are automatically processed via **ImageMagick**, compressed for web performance, and synced to the live site via **GitHub** and **Vercel**.
- **Live Data Sync:** By leveraging a Google Sheets integration, the directory remains "live," allowing for real-time updates to employee names, roles, and details without requiring manual code changes.

**Technical Objectives** This assignment serves as a deep dive into the intersection of **Brand Identity** and **Full-Stack Automation**. The goal was to build a system that is not only visually aligned with Polygon Technology's professional aesthetic but also functionally sustainable. By hosting the project on GitHub and deploying via Vercel, the application demonstrates a professional-grade deployment cycle, ensuring that the "Faces of Polygon" directory is fast, reliable, and permanently accessible.
